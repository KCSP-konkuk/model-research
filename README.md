# redpepper — 홍고추 도매가격 · 서울 전통시장 소매가 예측

AgriForecast(건국대 팀프로젝트)에 붙일 순별 가격 예측 모델의 데이터·실험 저장소. 모델이 두 갈래다.

| 모델 | 대상 | 상태 | 문서 |
|---|---|---|---|
| **도매** | 가락시장 홍고추 경락가 | 서비스 운영 중. 시험 MASE 0.659 | 이 README, [`docs/METHOD.md`](docs/METHOD.md) |
| **소매** | 서울 전통시장(경동·복조리) 소매가, KAMIS | 붉은고추 0.620 · 양배추 0.663 · 양파 0.684 (시험 MASE). 붉은고추·양배추 서비스 운영 중 | [아래 요약](#소매가-예측-2026-09-29), [`docs/RETAIL.md`](docs/RETAIL.md) |

서비스 파이프라인은 [aws-agriforecast](https://github.com/KCSP-konkuk/aws-agriforecast) 에 있고,
여기에는 품목 선정부터 피쳐 선택·튜닝·최종 성능 검증까지의 근거가 들어 있다. 아래 "무엇을 예측하나"부터 "재현"까지는 **도매 모델** 설명이다.

## 무엇을 예측하나

| 항목 | 값 |
|---|---|
| 대상 | 서울 가락시장 **홍고추 경락가, 상 등급, 10kg 상자** (농넷 품목 24210 / 규격 10) |
| 단위 | **원 / 10kg 상자** |
| 예측 값 | 다음 1순(상순 1\~10일 · 중순 11\~20일 · 하순 21일\~말일)의 **거래일 평균가** |
| 예측 시점 | **순이 시작되는 날 새벽 1회** — 예측 대상 순의 가격은 하나도 보지 않는다 |

순 중간에 이미 지난 날을 보고 다시 예측하면 오차가 1%대까지 줄지만, "지난 날 평균 + 최신가 유지"라는
단순 계산도 똑같이 줄어든다. 모델 실력이 아니라 답을 일부 본 효과이므로 쓰지 않는다([METHOD 10.3](docs/METHOD.md)).

## 성능

**시험 2021\~2025 (180순)** — 피쳐·파라미터는 검증 2016\~2020 에서만 고르고, 이 구간은 마지막에 한 번만 봤다.

| | MASE | MAPE | MAE (원) | RMSE (원) | R² | RMSSE | 방향 적중률 |
|---|---|---|---|---|---|---|---|
| 나이브 (직전 순 가격 그대로) | 1.000 | 24.7% | 21,268 | 28,089 | 0.629 | 1.000 | — |
| 이전 모델 (같은 방식으로 재튜닝) | 0.749 | 18.5% | 15,937 | 21,581 | 0.781 | 0.768 | 71.1% |
| **채택 모델** | **0.659** | **16.1%** | **14,006** | **19,006** | **0.830** | **0.677** | **76.1%** |

- **연도별 MASE**: 0.71 · 0.66 · 0.63 · 0.64 · 0.67 — 5년 모두 1 미만, 5년 모두 이전 모델(0.77 · 0.77 · 0.68 · 0.76 · 0.77)보다 낫다
- **Diebold-Mariano 검정** (HLN 소표본 보정)
  - 나이브 대비: 절대오차 t=-6.21 (p=3.5×10⁻⁹), 제곱오차 t=-5.40 (p=2.1×10⁻⁷)
  - 이전 모델 대비: 절대오차 t=-2.45 (p=0.015), 제곱오차 t=-2.46 (p=0.015)
- **2026년 1\~9월 (26순, 어떤 결정에도 안 쓴 데이터)**: MAPE 15.6% · MASE 0.655 · R² 0.760 (나이브 MAPE 24.9%)

> **MASE** 는 나이브 대비 오차 비율이다. 0.659 = 직전 순 가격을 그대로 쓸 때보다 오차가 34% 작다.
> 홍고추는 순마다 평균 25% 가까이 움직이는 품목이라(나이브 MAPE 24.7%) MAPE 만으로 다른 품목과 비교하면 안 된다.

## 모델

```
① 피쳐 (순 t 시작 시점까지 알 수 있는 값만)
      ↓
② XGBoost 가 비율을 예측     r̂ = 순 t 가격 ÷ 순 t-1 가격        예) 1.08
      ↓
③ 가격으로 환산              예측가 = r̂ × 순 t-1 가격            예) 40,000 × 1.08 = 43,200원
```

- **왜 비율인가**: 트리 모델은 학습에서 본 값의 범위 밖으로 예측하지 못한다. 홍고추는 연 최고가가 8만\~25만 원으로
  해마다 가격대가 달라, 가격을 직접 맞히게 하면 처음 보는 가격대에서 무너진다. 비율은 가격대와 무관하게 비슷한 범위에 있다
- **학습 데이터**: 2001년 1월부터(926순). 농넷이 2001년까지 제공한다는 걸 확인해 기존 2018\~ 대비 표본을 3배로 늘렸다
- **피쳐 선택**: 학습할 때마다 중요도 상위 **60개**만 남긴다(학습 구간 안에서만 고르므로 누설 없음)
- **하이퍼파라미터** (`experiments/best_split.json` 의 `S 선택`): `max_depth 5`, `n_estimators 1200`, `learning_rate 0.08`,
  `subsample 0.8`, `colsample_bytree 0.9`, `min_child_weight 12`, `reg_lambda 1.0`, 손실 `reg:absoluteerror`
- **시드 12개 평균**: 단일 시드는 MASE 표준편차가 0.012 라 여러 시드를 평균한다

## 피쳐

### 채택

| 그룹 | 내용 | 빼면 (검증 MASE) |
|---|---|---|
| **막판 가격** `d_last1_vs_p1` | 직전 순 **마지막 거래일** 가격 ÷ 직전 순 평균. 직전 순이 끝날 무렵 가격이 평균보다 위였나 아래였나 | **+0.090** — 가장 중요 |
| **교차 품목가** | 풋고추·청피망 순별 가격의 시차·이동평균·모멘텀·평년/전년 대비, 홍고추와의 가격비 | +0.075 |
| **검색량** | 네이버 데이터랩 '고춧가루'(+'고추가루') 순평균의 시차·이동평균·전년 대비 | +0.014 |
| 가격 자기이력 | 홍고추 순별 가격의 시차(1\~36순)·이동평균·변동성·모멘텀, 평년·전년 대비, 계절(월·순) | (기본 그룹) |

- 막판 가격은 2001\~2026 **일별 가격을 새로 확보**해서 만든 피쳐다. 이것 하나로 이전 모델 대비 MASE 가 약 0.09 좋아졌다
- 검색량은 데이터랩이 **2016년부터만** 있어 2001\~2015 학습 행에서는 비어 있다(XGBoost 가 결측을 처리). 그래도 빼면
  검증·시험 모두 나빠진다(시험 0.659 → 0.682)

### 시험했지만 뺀 것

검증 2016\~2020 에서 **시드 노이즈(0.012)보다 크게 좋아지지 않으면 넣지 않는다**는 규칙을 실행 전에 정하고 판정했다.

| 피쳐 | 넣었을 때 (검증 MASE 변화) | 비고 |
|---|---|---|
| 명절·수확기·김장철 더미 | 빼도 +0.004 | 이전 모델엔 있었으나 제거 |
| 기상 (ASOS, 산지별 계절 전환) | +0.001 | |
| 물가지수 (PPI 건고추·고추가루) | -0.007 | 노이즈 범위 |
| 재배면적·생산량 | +0.001 | 가격 "수준"은 설명하지만 "다음 변화"는 못 맞힌다([METHOD 7](docs/METHOD.md)) |
| 반입량 | +0.002 | |
| 출하지역 (1·2위 산지, 집중도) | +0.004 | |
| 검색량 최근 3·7일 (일별) | -0.000 | 순평균 검색량으로 충분 |
| 앵커를 최신 일별 가격으로 교체 | — | 비율의 분모를 바꾸는 건 효과 없음. 막판 가격은 **피쳐로** 넣어야 듣는다 |

그 밖에 LightGBM·RF·Ridge·Huber, 앙상블, 상·중·하순 분리 모델도 XGBoost 단일 모델보다 낫지 않았다.

## 평가 방법

| 구간 | 연도 | 쓰임 |
|---|---|---|
| 학습 | 평가하는 해 y 마다 **2001 \~ y-1** (확장 윈도우) | 모델 적합 |
| 검증 | 2016 \~ 2020 | 피쳐·K·하이퍼파라미터 선택만 |
| 시험 | 2021 \~ 2025 | 다 고른 뒤 한 번만 성능 측정 |
| 추가 | 2026 (1\~9월) | 어떤 결정에도 안 씀 |

- 시간 순서대로 나눈다. 무작위로 섞으면 미래로 과거를 맞히게 된다
- 주 지표는 **MASE**(나이브 대비). R² 는 계절성이 큰 품목에서 부풀려지므로 단독으로 보지 않는다
- 이전 모델(9/22)은 튜닝과 보고를 같은 구간에서 했다. 이번에 분리해 다시 했고, 결과는 거의 같았다(0.658 → 0.659)

## 재현

```bash
pip install -r requirements.txt     # xgboost 3.2.0 · pandas 2.2.3 고정 (버전이 바뀌면 수치가 달라진다)
cd experiments

# 피쳐 선택 → 튜닝 → 시험 전체 (약 1시간 반)
python select_tune_test.py

# 튜닝은 건너뛰고 채택 설정으로 시험만 (약 7분)
RESUME="C0 현행=80:30,S 선택=60:0" python select_tune_test.py
```

`collect/` 의 수집 스크립트 중 기상청·KOSIS·데이터랩은 API 키를 서버 설정 파일에서 읽는다(키는 이 저장소에 없다).
농넷은 인증이 없지만 **과다 요청으로 차단된 적이 있다** — 요청 간격 1초 이상을 지킬 것.

## 소매가 예측 (2026-09-29\~)

KAMIS Open API 소매가 중 **서울 경동·복조리 두 전통시장 평균**을 순 단위로 예측한다. 서울 평균은 판매처 구성이 바뀔 때마다 출렁여서 쓰지 않는다.
홈 화면에는 **1순 뒤 예측만** 띄운다. 방법·수치 전부는 [`docs/RETAIL.md`](docs/RETAIL.md).

**붉은고추 1순 뒤 — 시험 2022\~2025 (144순)**. 검증 2017\~2021 에서만 골랐다.

| | MASE | MAPE | NMAE | R² | 방향 적중률(3분류) |
|---|---|---|---|---|---|
| 나이브 (직전 순 그대로) | 1.000 | 9.08% | 9.82% | 0.751 | 20.1% |
| **모델** | **0.620** | **5.65%** | **6.09%** | **0.916** | **70.8%** |

**양배추·양파 1순 뒤 — 시험 2022\~2025 (144순)**. 구성은 붉은고추와 같다

| | MASE | MAPE (나이브) | NMAE | R² | 방향 적중률 | DM p |
|---|---|---|---|---|---|---|
| 양배추 | **0.663** | 4.54% (6.98%) | 4.73% | 0.900 | 68.1% | 5.2×10⁻⁹ |
| 양파 | **0.684** | 1.67% (2.44%) | 1.71% | 0.963 | 76.4% | 8.6×10⁻⁵ |

- 피쳐: 소매 자기이력 + **가락 경매가**(가장 중요 — 빼면 나이브 수준) + **소매 막판 가격**(직전 순 마지막 조사일 ÷ 순 평균)
- 양배추에 붙인 산지 전환 플래그·제주·서귀포·태백 기상은 효과가 없었다(기상은 오히려 나빠짐)
- XGBoost 비율 타깃, 상위 5 파라미터 앙상블 × 시드 12. 연도별 MASE 0.63 · 0.59 · 0.64 · 0.62, 나이브 대비 DM p=1.8×10⁻⁷
- 소매가는 도매보다 훨씬 덜 움직인다(나이브 MAPE 9.1% vs 도매 24.7%). **MAPE 로 도매와 비교하지 말 것** — MASE 로는 소매 0.620 < 도매 0.659
- 코드 `experiments/retail/`, 데이터 `data/retail/`(KAMIS 소매 78,856행, 양파·양배추 가락 일별 2013-12\~, 도매 예측 재현값)
