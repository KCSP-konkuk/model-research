# 서울 전통시장 소매가 예측 — 방법과 성능

2026-09-29 작업 기록. 홍고추 도매 모델(`METHOD.md`)의 틀을 소매가로 옮겼다.
품목은 붉은고추 · 양배추 · 양파 순서로 하나씩 진행했다. **세 품목의 1순 뒤 구성은 셋 다 같다(소매 + 가락 + 소매 막판).**
2026-09-30 에 **애호박 · 시금치**, 2026-10-02 에 **오이(다다기) · 꽈리고추 · 피망 · 파프리카**를 더했다. 가락 경매가 대신 KAMIS 도매(중도매인 판매가)를 쓴다(12절).
홈 화면에는 **1순 뒤(h=1) 예측만** 띄운다(사용자 결정). 2·3순 뒤도 학습·측정했고 아래에 함께 적는다.

실험 코드는 `experiments/retail/`, 데이터는 `data/retail/`.

## 1. 예측 대상

| 항목 | 값 |
|---|---|
| 가격 | KAMIS Open API 17번 `periodRetailProductList`, 서울(`1101`), 상품(`04`) 등급 소매가 |
| 판매처 | **경동 · 복조리 두 전통시장 평균**(그날 값이 있는 곳만) |
| 단위 | 순(1\~10일 상순 / 11\~20일 중순 / 21일\~ 하순) 평균. 붉은고추 원/100g, 양배추 원/포기, 양파 원/kg |
| 기간 | 2014-07 상순 \~ 2026-09 중순, 440순 |

**서울 평균을 쓰지 않는 이유.** KAMIS 의 서울 평균은 전통시장과 대형유통(익명 A\~L-유통)이 섞였고 대형유통이 30\~70% 싸다.
판매처 구성이 바뀌면(2016.8 대형유통 확대, 2021.1 영등포 폐지, 2023.07 대형유통 개편) 가격 변화 없이 평균이 출렁인다.
경동(세 품목 2014-01\~)과 복조리(2014-07\~)는 이 기간 내내 조사됐다.
목표 후보를 비교한 throwaway 실험에서도 두 곳 평균이 경동 단독보다 세 품목 모두 나았다.

**소매가는 도매보다 훨씬 경직적이다.** 나이브(직전 순 유지)가 매우 강한 기준선이다.

| 양파 | 2.1% | 94% |
| 양배추 | 6.2% | 85% |
| 붉은고추 | 7.5% | 85% |

## 2. 평가 설계

| 항목 | 값 | 이유 |
|---|---|---|
| 예측 시점 | 순 t 의 첫날 1회 | 홍고추와 같다(METHOD 10.3) |
| 쓸 수 있는 정보 | 소매 t-1 순까지, 가락 경매가 t-1 순 마지막 거래일까지 | 월 통계는 발표일 이후만 |
| 예측 기간 h | 1·2·3순 뒤, **h 마다 따로 학습**(direct) | h=1 → 순 t, h=3 → 순 t+2 |
| 학습 타깃 | `y[t+h-1] / y[t-1]` (비율) | 트리가 새 가격대에서 무너지지 않게 |
| 나이브 | `y[t-1]` 유지 | 모든 MASE 의 분모 |
| 모델 | XGBoost, `reg:absoluteerror` | 제곱오차(0.632)·Huber(0.707)보다 절대오차(0.585)가 나았다(검증 3년, h=1) |
| 학습 | 평가 연도 Y 마다 **목표 순이 Y 이전인 행**으로(확장 윈도우) | h>1 에서 Y 에 걸친 목표가 학습에 새지 않게 |
| **검증** | **2017 \~ 2021 (5년)** | 피쳐 선택·파라미터 선택 **만** |
| **시험** | **2022 \~ 2025 (144순)** | 다 고른 뒤 측정 |
| 추가 | 2026 (26순) | 어떤 결정에도 안 씀 |
| 판정폭 | 검증 MASE **±0.012** | 시드 노이즈 σ: h=1 0.002 · h=2 0.009 · h=3 0.007 |

### 보고 지표

METHOD 2절의 묶음에 두 가지를 더했다.
- **NMAE** = Σ\|오차\| / Σ실측. aT·DACON 2024 물가 예측 대회의 지표다. 다만 대회는 도매가·다른 품목이라 **순위 비교는 못 한다**
- **DA3**(3분류 방향): 나이브 대비 ±2% 안이면 '비슷'. 소매는 안 움직이는 순이 많아 2분류로는 의미가 없다. 나이브는 항상 '비슷'이다
- **국면별 MASE**: 직전 순 가락 변화가 상위 30% 인 순(큰 변동) / 나머지(평온). 평온한 순에는 나이브가 거의 이기므로 전체 평균만 보면 가치를 과소평가한다

## 5. 붉은고추

### 5.1 피쳐 선택 (검증 2017\~2021, 기본 파라미터, 시드 4)

핵심 = 소매 + 가락에서 시작해 후보를 하나씩 더했고, 판정폭을 넘을 때만 넣었다. `experiments/retail/tune5_pepper.py`

| + 가락 최근 5·10일 | -0.011 | -0.001 | +0.002 |

(표의 숫자는 그 시점까지 채택된 구성 대비 변화)

- **가락 경매가가 거의 전부다.** 빼면 h=1 이 0.93 으로 나이브 수준이 된다(검증 3년 기준 +0.271)
- **h=1 은 소매 막판, h=2·3 은 도매 예측.** 1순 뒤는 직전 순 안에서 소매가 이미 움직였는지가 가장 직접적인 신호다. 2·3순 뒤로 갈수록 "가락이 어디로 갈지"가 중요해진다
- 도매 모델에서 효과가 컸던 교차 가격·검색량은 소매에서 효과가 없다. 가락 경매가에 이미 담겨 있다
- 판매처 분리(경동·복조리 따로)는 단독으로 -0.028 이었지만 소매 막판과 겹쳐 같이 넣으면 +0.024 였다 → 제외(검증 3년)

### 5.2 튜닝

### 5.5 거쳐 온 과정 (반복하지 말 것)

1. **검증 3년(2019\~2021)으로 먼저 했다가 바꿨다.** 거기서 고른 튜닝이 시험으로 옮겨지지 않았다.
   - 검증에서는 0.02\~0.04 개선이었지만, 시험에서는 기본값이 같거나 나았다. h=2 는 기본값이 유의하게 나았다(p=0.019)
   - h=1 도 검증 0.628 → 시험 0.704 로 벌어졌다
   - 검증 108순이 좁아 선택이 노이즈에 맞춰진 것으로 본다. 그래서 **검증을 5년(180순)으로 넓히고 상위 5 앙상블**로 바꿨고, 재현됐다(0.607 → 0.620)
2. **시험 구간을 두 번 봤다.** 3년 검증 구성으로 한 번, 5년 검증 구성으로 한 번. 두 번째 선택도 검증만으로 했지만 기록으로 남긴다
   - 3년 검증 때 h=3 구성(교차 + 반입량 포함)은 시험 0.694 였고, 5년 검증 구성은 0.719 다. 시험을 보고 되돌리지 않았다
3. **시험 연도(2022)의 오차를 보고 피쳐를 만들지 않았다.** 오차 분석은 검증 구간에서만 했다
4. **6\~7월 노지 전환기.** 검증 3년에서 h=1 이 6월 1.08 · 7월 1.48 로 나이브 이하였다
   - 가락→소매 전이율(같은 달 과거 3년, 원점 회귀 β)을 재 보니 봄 0.31\~0.42, **6\~7월 0.13\~0.18**, 9월 0.14 였다. 가락이 크게 움직여도 소매가 거의 따라가지 않는다
   - 이를 피쳐(`f_passthrough`)로 넣었지만 판정폭을 못 넘었다. 시험에서는 6월 0.51 · 7월 0.83 으로 나이브보다 낫다
   - **정정(2026-09-29)**: 처음 잰 값(+0.011 / -0.005)은 `pt_expected` 가 **대상 순의 가락 가격을 쓰는 누수**가 있던 버전이다. 고친 뒤 다시 재도 +0.008 / +0.005(검증 3년), +0.003 / +0.002(검증 5년)로 결론은 같다. 최종 모델엔 들어간 적이 없다
